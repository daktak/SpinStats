# SpinStats for intervals.icu

Android client for [intervals.icu](https://intervals.icu) to analyze spin/cycling training data.

## Features

- Runtime API key configuration via Settings screen
- Browse activities from intervals.icu
- View activity details and streams data
- Built with Jetpack Compose, Hilt, Navigation, and DataStore

## Setup

1. Build the project: `./gradlew :app:assembleDebug`
2. Install the APK on your device/emulator
3. Open the app and go to Settings to enter your intervals.icu API key and athlete ID
4. Use the app to browse and analyze your activities

## Requirements

- Java 21
- Android SDK 34

## Build Instructions

```bash
./gradlew :app:assembleDebug
```
